Privacy policy

What progLog stores

Your account profile, saved games, sessions, achievement progress, friends and settings are stored in Firebase Firestore when you are signed in. Local fallback data may remain in your browser when Firebase is not configured.

External services

RAWG is used for game discovery and metadata. Steam connection uses Valve's Web API through a Cloudflare Worker. API keys are stored as Worker secrets rather than in this GitHub Pages frontend.

Cookies and browser storage

progLog uses essential browser storage for theme preference, cookie-consent state and application functionality. The site does not use advertising cookies.

Your control

Use the settings and profile pages to control visibility. Delete stored data from your Firebase project when you need full account-level removal.
